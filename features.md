# Project Features

## SCRUM-266 - DG Cluster Assortment Advisor Dashboard

### Feature Summary
A single-screen dashboard enabling Dollar General category managers to view sales KPIs, evaluate SKU recommendations, select scenarios (Conservative, Balanced, Aggressive), verify guardrails, and submit assortment changes with an audit trail.

### Key Features
- KPI Header Strip: Real-time visibility into sales per linear foot, private brand %, in-stock rate, and shelf capacity.
- SKU Performance Table: Detailed Snacks SKU metrics with automated action status badges (GROW, MAINTAIN, SWAP, REDUCE).
- Interactive Scenario Selector: Compare Conservative, Balanced (default), and Aggressive scenarios with instant inline approval review panel updates.
- Approval Review Panel & Guardrail Verification: Inline verification of operational guardrails (capacity limits, private brand share) and final submission.
- Inline Audit Trail Confirmation: Post decisions with instant inline audit trail summary logging.
