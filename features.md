# Project Features

## SCRUM-58 - Project Tagging for Time Entries & Daily Summary Grouping

### Feature Summary
Allows users to create and manage color-coded projects, tag time entries, view daily time summaries grouped by project with color badges, and enforce deletion constraints when time entries are linked.

### Key Features
- Timer Control (Start/Stop)
- Manual Time Entry
- Daily Summary Grouped by Project
- Dark Mode Toggle
- Project Management (CRUD)
- Time Entry Project Tagging
- Project Deletion Validation & Constraint
- Project Selector Dropdown & Mandatory Tagging Validation
- Backend & Foreign Key Integrity Constraints on Deletion
